# Ashlesha Meshram | Frontend Portfolio

## Summary

A responsive personal portfolio website built with React as the beginner-level project of my Frontend Developer internship. It showcases my skills and projects, and works on mobile, tablet and desktop.

## Tech Stack

- React
- Vite
- CSS (with CSS variables)
- JavaScript
- react-icons
- Vercel (deployment)

## Features

- Home section with introduction and call-to-action buttons
- About section
- Skills section
- Projects section
- Contact form with validation
- Fully responsive layout (desktop, tablet, mobile)
